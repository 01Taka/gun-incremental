# 銃的当てインクリメンタル (Gun Incremental) MVP 🎯

短時間ラウンド制のインクリメンタル型「的当てゲーム」のMVP（最小動作プロダクト）です。  
**Phaser 4 + TypeScript + React + Vite + Tailwind CSS** で構築されており、**スマホ縦画面（900×1600）最適化**・PCブラウザの双方で快適に片手・ワンハンド操作できます。中央の射撃ゾーンは正方形エリア（800×800）として設計されています。

---

## 🎮 ゲーム概要と遊び方

### ひとことで言うと

銃で的を撃って壊し、得た賞金（`sp`）で自分を強化していくウェスタン風インクリメンタルゲームです。  
ただし一定ラウンドごと（`INVOICE_CONFIG.intervalRounds` ラウンド周期）に**「保安官の上納金（請求）」**として所持金を支払う必要があり、払えなければ町から追放（ゲームオーバー）。  
ゲームオーバーになっても、それまでに支払った上納金総額の一定割合（`INVOICE_CONFIG.permanentPointRate`）が**「名声バッジ（永続ポイント）」**になり、酒場での永続強化で次回ランが有利になります。  
最終目標は、手配ポイント（`targetPoints`）を貯めて**全種類の的（賞金首）をすべて解放すること（ゲームクリア）**です！

### 遊びの流れ

1. **ラウンド**: 画面最上部に賞金首出現エリア、中央下に銃が配置されています。画面のどこでもタップ＆上下スライドすることで銃の角度を直感的にエイムでき、**射線がいずれかの的に合っている間だけ**直線的に弾丸が自動発射されます（タップした位置が中央基準となり銃は正面に戻り、指を離しても角度は維持）。基本制限時間は `ROUND_CONFIG.baseDuration`（開幕カウントダウン: `ROUND_CONFIG.countdownDuration`）。弾倉（`magazineSize`）が空になると自動リロード（`reloadTime`）が行われます。
2. **リザルト**: 獲得賞金や手配ポイント進捗を確認。「次のラウンドへ」直行か「強化する」を選択。
3. **強化**: 所持金を使い、スキルツリー（全ノード）や武器ショップ（指定ラウンド `PROGRESSION_CONFIG.shopUnlockRound` 以降解放）で強化。
4. **保安官の上納金**: `INVOICE_CONFIG.intervalRounds` ラウンド目で紹介イベントが発生し、`INVOICE_CONFIG.intervalRounds * 2` ラウンド目から定期的に所持金で支払い。支払えなければゲームオーバー。支払いに成功すると提示された候補（`PROGRESSION_CONFIG.passiveChoicesCount` 択）から**パッシブ**を獲得。
5. **ゲームオーバー & 永続強化**: 上納金の支払総額 × `INVOICE_CONFIG.permanentPointRate` を名声バッジ（永続ポイント）として獲得し、酒場で次回ラン以降に引き継がれる永続強化を購入。
6. **クリア**: 累計手配ポイントを貯め、全種の的（無法者〜黄金の賞金首）を解放した時点でゲームクリア！

## 🧩 登場要素一覧

### 🔫 武器 (全3種: `src/config/weapons.json`)

各武器は発射間隔（`fireInterval`）、基礎威力（`damage`）、装弾数（`magazineSize`）、リロード時間（`reloadTime`）、購入価格（`price`）、解放ラウンド（`unlockRound`）、弾丸特性（`bullet.speed`, `bullet.radius`）などのパラメータを持ちます。

- **ピースメイカー (ハンドガン / `handgun`)**: 初期所持武器（`PROGRESSION_CONFIG.initialWeaponId`）。低威力の代わりに扱いやすい連射・リロード設定を持つ6連発リボルバー。
- **ウィンチェスター銃 (ライフル / `rifle`)**: `unlockRound`（ショップ解放）以降に購入可能。高速連射と大容量マガジンを誇るレバーアクション連発銃。
- **シャープス大口径銃 (スナイパー / `sniper`)**: `unlockRound` 以降に購入可能。極太の大口径弾と高い基礎威力を誇る重ライフル。
- ※ 所持武器数が `PROGRESSION_CONFIG.autoFireUnlockWeaponCount` に達する、またはゲームクリア達成で「オートエイム（自動照準）」が解放されます。

### 🎯 的 / 賞金首 (全6種: `src/config/targets.json`)

手配ポイントが各標的の `unlockPoints` に達することで順次解放されます。耐久値（`hp`）、基本賞金（`baseSp`）、出現重み（`weight`）、判定半径（`radius`）、生存限界時間（`lifetime`）などのパラメータを持ちます。

1. **無法者 (標準 / `standard`)**: `unlockPoints: 0`（初期解放）。基本となる低HPの標準標的。
2. **懐中時計 (時間の的 / `time`)**: 撃破時にラウンド制限時間を延長（`ROUND_CONFIG.timeTargetBaseExtension` + スキル補正）。
3. **鉄板の重罪人 (硬い的 / `hard`)**: 胸に鉄板を仕込んだ高耐久（高 `hp`）・高賞金（高 `baseSp`）の標的。
4. **ダイナマイト樽 (誘爆の的 / `electric`)**: 撃破時に大爆発し、とどめの一撃に応じた誘爆ダメージ（`chainDamage` 倍率）を全標的に与える。
5. **早撃ちキッド (小さい的 / `small`)**: 小柄（小 `radius`）で素早く逃走する（`lifetime` あり）が高額賞金な標的。
6. **黄金の賞金首 (金の的 / `gold`)**: 最大の `unlockPoints` を要する伝説的大悪党。高 `hp` かつ `lifetime` 付き。解放でゲームクリア！

### ⚡ スキルツリー (`src/config/skillTree.json`)

ラン中に獲得した賞金（`sp`）を消費してアンロック・強化するツリー形式の強化システムです。  
各ノードには最大レベル（`maxLevel`）、段階ごとのコスト（`costs`）、強化対象ステータス（`effect.stat`）、レベルあたりの効果量（`effect.perLevel`）が定義されており、威力・連射速度・装弾数・リロード時間・制限時間・賞金倍率・手配ポイント倍率などを強化できます。

### 📜 パッシブ (`src/config/passives.json`)

上納金の支払い成功時にランダムな候補（`PROGRESSION_CONFIG.passiveChoicesCount` 択）から選択して獲得するボーナスです。取得ごとに効果量（`effectPerStack`）が累積スタックします。

### ⭐ 永続強化 (酒場: `src/config/permanentUpgrades.json`)

上納金の支払総額に応じた名声バッジ（支払額 × `INVOICE_CONFIG.permanentPointRate`）を消費して購入する恒久強化です。段階コスト（`costs`）と段階効果量（`effects`）が定義されており、次回以降のすべてのランに引き継がれます。

## 💻 開発・実行コマンド

### 開発サーバー起動

```bash
npm run dev
```

### プロダクションビルド（型検査・Lint・フォーマット含む）

```bash
npm run build
```

### バランスシミュレーションの実行（ヘッドレス自動プレイ）

```bash
npm run test:sim
```

> コマンドライン上でAIがプレイを自動模倣し、初回プレイでの請求耐用回数、周回ごとのメタ進行、クリア到達ラウンドを高速検証します。

## 🏛 アーキテクチャ

- **`src/config/`**: ゲーム定義データ（武器、的、スキル、パッシブ、永続強化）と型定義
- **`src/logic/`**: 純粋なゲームロジック・計算・ステート管理（`GameState.ts`）、シード付き乱数（`SeededRandom.ts`）、セーブ（`storage.ts`）、ヘッドレスシミュレータ（`Simulation.ts`）
- **`src/scenes/`**: Phaser 4 による画面・演出・入力処理（Title, Round, Result, Upgrade, Invoice, GameOver, PermanentUpgrade, Clear）
- **`src/audio/`**: Web Audio API によるシンセサイザー合成音・音量管理
