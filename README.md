# 銃的当てインクリメンタル (Gun Incremental) MVP 🎯

短時間ラウンド制のインクリメンタル型「的当てゲーム」のMVP（最小動作プロダクト）です。  
**Phaser 4 + TypeScript + React + Vite + Tailwind CSS** で構築されており、PC・スマホ（横画面）の双方で快適に動作します。

---

## 🎮 ゲーム概要と遊び方

### ひとことで言うと

銃で的を撃って壊し、得たポイント(SP)で自分を強化していくゲームです。  
ただし5ラウンドごとに**「請求」**としてSPを支払う必要があり、払えなければゲームオーバー。  
終わるたびに支払額の2%が**「永続ポイント」**になり、永続強化で次回ランが有利になります。  
最終目標は、**全6種類の的をすべて解放すること（ゲームクリア）**です！

### 遊びの流れ

1. **ラウンド（約7秒）**: 画面に出る的をクリック・タップ（長押しで連射）して壊します。
2. **リザルト**: 獲得SPや的ポイント進捗を確認。「次のラウンドへ」直行か「強化する」を選択。
3. **強化**: SPを使い、スキルツリー（全10ノード）や武器ショップ（全3種）で強化。
4. **請求（5ラウンドごと）**: SPで支払い。支払えなければゲームオーバー。支払えたら**パッシブ3択**を獲得。
5. **ゲームオーバー & 永続強化**: 支払額の2%を永続ポイントとして獲得し、次回ラン以降に引き継がれる永続強化を購入。
6. **クリア**: 累計的ポイントを貯め、全6種の的を解放した時点でゲームクリア！

## 🧩 登場要素一覧

### 🔫 武器 (3種)

- **ハンドガン**: 発射間隔 0.30s / ダメージ 1 (初期所持)
- **ライフル**: 発射間隔 0.60s / ダメージ 3 (Round 3以降ショップで購入可能)
- **スナイパー**: 発射間隔 1.20s / ダメージ 8 (ショップで購入可能)
- ※ 3つの武器を揃えると「オート射撃」が解放されます。

### 🎯 的 (全6種)

1. **標準**: HP 1 / SP 5 (初期解放)
2. **硬い的**: HP 5 / SP 25 (装甲が硬い)
3. **金の的**: HP 2 / SP 80 (1.5秒で消滅、最優先ターゲット)
4. **電撃の的**: HP 3 / SP 22 (破壊時に他の的へ連鎖放電ダメージ)
5. **小さい的**: HP 2 / SP 22 (当たり判定小、素早く正確に狙う)
6. **時間の的**: HP 3 / SP 12 (破壊でラウンド制限時間が延長！)

### ⚡ スキルツリー (全10ノード)

- 基礎ダメージ、ラウンド時間延長、連射間隔短縮、SP倍率、同時出現数、会心の一撃、的ポイント獲得量、ショップ割引、時間の的延長量、連鎖ダメージ強化

### ⭐ 永続強化 (5種×3段階)

- 初期資金 (開始SPボーナス)
- 射撃適性 (基礎ダメージ増加)
- 集中力持続 (ラウンド制限時間延長)
- 研究効率化 (的ポイント獲得量増加)
- 税務対策 (5ラウンドごとの請求額軽減)

## 💻 開発・実行コマンド

### 開発サーバー起動

```bash
npm run dev
```

### プロダクションビルド（型検査・Lint・フォーマット含む）

```bash
npm run build
```

### バランスシミュレーションの実行（ヘッドレス自動プレイ）

```bash
npm run test:sim
```

> コマンドライン上でAIがプレイを自動模倣し、初回プレイでの請求耐用回数、周回ごとのメタ進行、クリア到達ラウンドを高速検証します。

## 🏛 アーキテクチャ

- **`src/config/`**: ゲーム定義データ（武器、的、スキル、パッシブ、永続強化）と型定義
- **`src/logic/`**: 純粋なゲームロジック・計算・ステート管理（`GameState.ts`）、シード付き乱数（`SeededRandom.ts`）、セーブ（`storage.ts`）、ヘッドレスシミュレータ（`Simulation.ts`）
- **`src/scenes/`**: Phaser 4 による画面・演出・入力処理（Title, Round, Result, Upgrade, Invoice, GameOver, PermanentUpgrade, Clear）
- **`src/audio/`**: Web Audio API によるシンセサイザー合成音・音量管理
